# SoLoData project guidance

## Scope and source of truth

This directory contains a local Windows microscopy application and its image-processing pipeline. The sibling `../Presentanion` (intentional existing spelling) contains the canonical bilingual slide decks. Communicate with the owner in Russian unless asked otherwise. Follow the current user request before repository preferences.

Read `README.md`, `README_RU.md`, and the relevant source before changing behavior. Existing review documents describe different historical versions; source and reproducible tests establish current behavior. Do not describe proposals as implemented features or historical benchmark numbers as new measurements.

## Entry points and architecture

- `app.py`, `launch_app.cmd`, `launch_app.ps1`: desktop startup. `main.py`: command-line pipeline.
- `src/app_settings.py`: validated per-run `PipelineSettings`. `src/config.py`: defaults and some historical/experimental constants.
- `src/image_io.py`: TIFF axes, explicit channel/plane selection, native pixels and uint8 processing view. uint16 processing uses a right shift by 8, not percentile normalization.
- `src/tiff_calibration.py` reads supported OME/ImageJ physical X/Y sizes. Desktop automatic calibration resolves each source separately; manual mode is a batch override. Unequal X/Y, unknown units, print DPI and objective magnification must not become an automatic scalar calibration. Keep resolved calibration and origin in run/measurement provenance; never rewrite historical measurements on metadata detection.
- `src/block1_preprocessor.py`: bilateral filter, white top-hat with min-max normalization, reciprocal-gamma LUT. A separate protective mask uses modified Otsu, a lower threshold, closing, and dilation.
- `src/block2_slicer.py`: v3 adaptive tiling. Straight corridor search with backward-moving windows, directed `MCP_Geometric` routing, whole-component allocation, exact pixel ownership, native/model tiles and metadata.
- `src/partition_geometry.py`, `src/tile_scale.py`, `src/overview_reconstructor.py`, `src/tile_manager.py`: geometry, scale mappings, overviews and explicit tile exclusions.
- `src/black_tiles.py` checks exact zeros in valid active native pixels using the stored bit depth. `tile_exclusions.json` records automatic reasons, scanned file revisions and manual Restore overrides. Never decide emptiness from a model thumbnail or a positive brightness threshold. Automatic inspection runs in the desktop worker on private datasets. Excluded tiles retain their scientific files and appear as EXCLUDED on reconstructed maps; inclusion markers detect stale maps after manual changes.
- `src/block3_feature_extractor.py`: YOLO polygon import or explicitly selected automatic detection, local thresholding, component decomposition, six geometric/topological features, CSV and verification masks.
- `src/desktop/`: Qt interface, project persistence, worker process, provenance, localization, manual object labels and training export.
- `src/desktop/project_catalog.py` provides a derived `project.sqlite3` metadata index; `project.json` remains authoritative. Save JSON first, then synchronize the catalog; SQL queries must verify its JSON SHA-256. The catalog indexes sources, datasets and history, not scientific objects or pixels. `database_dialog.py` exposes checks, bounded browsing and metadata-only backups through Help; disable maintenance during workers. `tools/project_database.py` uses the desktop project lock. Never treat a metadata backup as a full project backup or silently replace an unknown SQLite schema. See `docs/DATABASE_RESEARCH_2026-11-11_RU.md` for the design, measurements and expansion plan.
- New UI projects own `<folder>/project.json` and all source copies, previews, runs, imported datasets, annotations, measurements and job logs below that folder. Import TIFFs and prepared tiles through cancellable workers; never mutate an external dataset from the UI. Startup reopens the last successfully selected project or falls back to `data/projects/default/project.json`. An explicit `--project` takes precedence. TIFF imports remain explicit. Keep legacy loads compatible.
- `storage_names.py` uses readable names (`sources/<filename>`, `runs/Preparation_001/tiles/<image>`, `previews/<image>/Preview_001`, `annotations/<image>/Labels_001`, `measurements/<image>/Measurement_001`); UUID identities stay in JSON. `storage_migration.py` journals reversible managed-path renames with exact project backups and preserves scientific file bytes. Preparation previews filter the whole native-resolution plane before reducing display PNGs to 2400 pixels; do not substitute a central crop or filter a downsampled input.
- `src/desktop/input_safety.py` prevents wheel edits to parameters; image wheel zoom remains enabled. `widgets.py` keeps ordinary previews bounded and opens original-resolution views separately (over 32 MP in the system viewer). `result_tile.py` highlights exact saved masks using `verification_masks/object_locations.json` and binary crop masks. Older grayscale crops require a unique exact foreground match; never guess an ambiguous location. Highlight coordinates are separate from predictors. `branding.py` and `assets/solodata.svg` define application identity; `tools/build_icon.py` and `tools/create_shortcut.ps1` rebuild icons and the Windows shortcut.
- `src/desktop/tile_edit.py` and `tile_editor.py` edit source-scale native pixels. Saving publishes an immutable native/model/mask bundle in `<dataset>/tile_edits/<tile>/Edit_001`. `src/tile_edits.py` resolves `active_tile_edits.json` while keeping stable tile filenames for annotations and CSV. Measurements fingerprint the active versions and require recalculation after edits. Older copy-only exports can be activated after source and scale checks. Editor defaults come from `EDITOR_DEFAULTS` and its separate version in `src/default_settings.py`.
- `src/desktop/label_database.py` owns authoritative per-measurement targets and audit events in `manual_object_labels.sqlite3`; the preserved JSON is a legacy import, not a current mirror. A storage marker prevents silent fallback when that authority is missing. One click writes one target/event transaction, with project history checkpointed later and recovered from the ledgers on load. CSV snapshots are cached only against reliable file revisions (including Windows change time); unknown revision support falls back to revalidation. Never rebuild target databases as if they were the project catalog. Snapshot JSON export is explicit.
- `src/object_classes.py`: shared stable class catalog. `src/desktop/object_classifier.py` is a manual classification UI, not a trained classifier.
- `segmentation_review.py` shows native/model images, exact masks and polygons. Ordinary Merge preserves gaps. `mask_connection.py` and `mask_correction_dialog.py` offer ranked skeleton ends, image-cost routing or straight bridges, width previews and binary paint/erase on the native grid. Accepted corrections require one 8-connected component; additions respect active validity and cannot contact unselected masks. `object_corrections.py` publishes unions, connected corrections and selected-mask deletions as new measurement versions; `object_merging.py` retains exact-mask loading and undo compatibility. All six predictors are recalculated for changed masks; unchanged IDs/labels survive and new IDs require class review. Native intensities and YOLO stay unchanged. Manual additions are stored separately and remain pink after reopening and later unions. Undo restores the intact parent, including deletion of every object. Full extraction starts fresh rather than silently reusing corrections. Mask-editor defaults have their own immutable catalog/version in `default_settings.py`. The seven-page workflow ends with Results (`analysis_page.py`); Object labeling precedes Model training.
- `test/test_*.py`: unittest regression suite. `test/Fiber Detection.py` is a historical experiment, not the automated test entry point.

## Scientific invariants

1. Distinguish the grayscale processing image, protective routing mask, annotation polygon, and thresholded measurement mask. Closing/dilation change dimensions; the protective mask is not a physical diameter mask.
2. Current preprocessing defaults: bilateral d=9, sigmaColor=45, sigmaSpace=15; top-hat radius=85 (171x171 ellipse); gamma=1.2 with exponent 1/gamma. Modified global Otsu ignores bin 0; protective threshold is `max(10, int(0.25*T))`; closing=17x17, buffer=5x5.
3. Default model tile size is 1500. The initial search window is [floor(0.75N), E), where the exclusive end E defaults to floor(0.975N) and can be set between floor(0.75N)+1 and N. The step is max(1, floor(0.015N)). Straight trials translate the window within independent left/up and right/down limits in source pixels. The maximum right/down shift is N-E. With the automatic end, automatic left/up and zero right/down retain the original trial sequence. Directed routing runs in the configured initial window with offsets (1,-1),(1,0),(1,1).
4. Obstacles have infinite route cost. Final preparation ownership preserves whole 8-connected protective components and assigns every source pixel exactly once. This is a guarantee about the protective mask, not unknown biological truth. Later manual tile edits can remove pixels and record those exclusions in their own validity masks and provenance.
5. v3 retains native crops for measurements even when an oversized crop is resized to a fixed model canvas. Respect valid masks, source coordinates, scale metadata, exclusions, and stale-result checks.
6. Current predictors: `Area`, `Aspect_Ratio`, `Solidity`, `Euler_Number`, `Endpoints`, `Branch_Points`. `Aspect_Ratio` is equivalent-ellipse major/minor axis ratio, not fiber centerline length/diameter. `Branch_Points` counts branch pixels, not merged graph junctions. Degenerate minor axes currently return 1.0; document this limitation rather than silently changing feature semantics.
7. `Area` uses source pixels in v3. With calibration s in micrometres/pixel, `Area_um2=Area*s*s`; the current training exporter adds `Area_um2` alongside the six core predictors. Do not infer physical units without calibration.
8. Six stable targets: particle=0, fiber=1, self_crossed_tube=2, crossed_tubes=3, agglomeration=4, adhered_objects=5. Keep IDs and CSV keys stable across UI languages.
9. The Model training page evaluates a baseline, decision tree and Random Forest on reviewed labels. Keep original sources or experiment groups intact in the 80/20 holdout and tune only within training groups. Exclude target/class columns and source identifiers from predictors. Inference on new objects and class-specific diameter/length measurement are future modules.
10. Search GIFs show actual attempted windows and reveal the accepted route. They do not show the priority-queue exploration frontier.
11. MCP checks occupied route vertices but permits diagonal corner crossing between two 8-connected obstacle pixels. The later `_allocate_components` stage repairs ownership for whole components; it does not recompute the seam. Do not attribute the final preservation guarantee to the route alone. A local reproducible counterexample is in `../Presentanion/presentation_source/reproduce_corner_case.py`.
12. Min–max normalization changes a value range, not a distribution into a Gaussian. Gamma=1 is an identity control. Gamma=1.2 raises faint background as well as faint signal and can change subsequent Otsu/local masks; improved segmentation is unproven without expert ground truth. The 2026-10-24 four-crop comparison measures protective coverage, not accuracy.

## Development and verification

Write source comments and docstrings in English. Explain intent, units, invariants, compatibility constraints and non-obvious tradeoffs where they help a reader. Keep comments near the relevant code and update them when behavior changes. Skip comments that merely restate a clear expression or function name. Keep user-facing text in the localization system.

Use Python 3.10+ with the versions in `requirements.txt`. On Windows, use the interpreter configured in ignored local_runtime.json, or the project virtual environment, as the launcher does. Use the bundled artifact runtime for slide work, not a replacement installation.

Typical checks from this directory:

```powershell
$env:QT_QPA_PLATFORM='offscreen'
& ".venv\Scripts\python.exe" -B -m unittest discover -s test -p 'test_*.py' -v
& .\launch_app.ps1 -SmokeTest
```

If sandbox ACLs prevent temporary-file creation, run tests with `tempfile.tempdir` set to a dedicated writable local temporary directory. Record that workaround separately from project defects. For targeted changes, run the relevant test modules before broadening checks. Scientific validation against expert masks is distinct from software regression tests.

Preserve existing user changes; the checkout may already be dirty. Do not reset or overwrite unrelated files. Do not regenerate full TIFF datasets, replace annotations, move tiles, or retrain models merely to update documentation. Use new output directories for experiments. Keep intermediate renders, caches and sample exports separate from canonical deliverables.

## In-app help maintenance

The built-in Help is the application manual, not only a list of parameter defaults. Every future application update that changes a feature, workflow, control, parameter, shortcut, export, validation rule, error or recovery behavior must update the relevant in-app Help topics in the same change. Keep all interface variants equivalent, including contextual question-mark links, search terms, units, valid ranges, worked examples and limitations. Verify the affected Help pages alongside the behavior being changed.

Factory settings must come from the versioned, immutable defaults catalog shared by runtime settings and Help. A user's project settings must never become the factory reference. When changing factory defaults, explicitly update the catalog version, reference explanations, translations and regression checks. Keep current editable values visibly separate from factory values. Invalid drafts must not be saved as working project settings or prevent the application from starting; preserve an exact backup before repairing saved settings.
