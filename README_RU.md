# SoLoData

Прежнее название — FiBreath. Существующие проекты и расположение панелей совместимы с обновлением. Название репозитория Fibers-Segmentation сохранено.

[Описание обновления SoLoData](docs/SOLODATA_RELEASE_2026-11-11_RU.md).

Локальное Windows-приложение для обработки микроскопических TIFF, подготовки тайлов, проверки и исключения изображений, импорта YOLO segmentation и извлечения признаков.

Знак **?** показывает краткое объяснение при наведении, а при нажатии открывает подробную справку.

## База данных и резервные копии

**«Справка → База данных проекта…»** проверяет локальный каталог SQLite и показывает сохранённые наборы и историю страницами по 100 строк. **«Обновить каталог»** создаёт или обновляет индекс; **«Пересоздать каталог»** сохраняет прежний повреждённый каталог в `backups/Database_catalog_001` перед заменой. Во время обработки эти действия недоступны.

Основным документом остаётся `project.json`. Сохранение проекта также обновляет производный `project.sqlite3` одной транзакцией; ошибка каталога не отменяет сохранение JSON. Простое открытие старого проекта не создаёт базу. Перед SQL-запросами проверяется SHA-256 JSON; устаревшие записи не выдаются. TIFF, тайлы, научные CSV, маски, ручные метки и модели остаются отдельными файлами. Актуальность каталога не означает актуальность измерений или наличие изображений.

**«Копия метаданных проекта…»** создаёт согласованные снимки JSON/SQLite с предупреждением `METADATA_ONLY.txt`. Для полной резервной копии остановите обработку, закройте SoLoData и скопируйте **всю папку проекта** на другой диск. Старые абсолютные пути к научным файлам могут потребовать перенастройки при переносе. Рабочий проект храните на локальном диске; общий SQLite-файл на сетевом диске или одновременное редактирование через облачную синхронизацию не поддерживаются.

Диагностика для разработчика: `python tools/project_database.py --project <project.json> status`; также доступны `sync`, `rebuild`, `list datasets --status ready`, `list history --action assign_object_class` и `backup <новая-папка>`. Команды обслуживания используют ту же блокировку проекта, что и приложение. [Подробное исследование и описание внедрения](docs/DATABASE_RESEARCH_2026-11-11_RU.md).

## Запуск

Дважды нажмите **launch_app.cmd**. Он проверяет настроенный интерпретатор, окружение проекта и PATH. Приложение использует Qt с PyQt6 или PySide6. Интернет для работы не требуется. SoLoData открывает последний успешно выбранный проект. Если он недоступен, откроется проект по умолчанию с пояснением. Явно указанный аргумент `--project` имеет приоритет.

Альтернативный запуск из корня проекта:

```powershell
& ".venv\Scripts\python.exe" -B app.py
```

Для другого компьютера установите Python 3.10+ и зависимости в локальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## Рабочий процесс

1. Создайте проект или откройте существующий файл проекта. Выберите исходные TIFF, канал и плоскость.
2. В «Подготовке» выберите TIFF, канал, срез/кадр, фильтры и размер тайла. Калибровка по умолчанию берётся из поддерживаемых метаданных каждого TIFF; доступен ручной режим. Знак **?** и **F1** открывают пояснения. Посмотрите всё изображение до запуска подготовки TIFF, отмеченных галочками.
3. В «Тайлах» проверьте обзор, модельные и native-изображения, исключите лишние ID и отметьте набор проверенным. Можно подключить прежний набор нарезки через папку с его `overview`/`native`/`valid_masks`.

Полностью чёрные тайлы исключаются автоматически при подготовке/импорте и первой проверке готового приватного набора на странице **«Тайлы»**. Проверяются строгие нули в действительных native-пикселях: даже один пиксель со значением 1 оставляет тайл активным, в том числе в 16-битных данных. Паддинг и уменьшенный предпросмотр модели не определяют исключение. В списке указана причина, а на картах сохраняются ID и оранжевая подпись **EXCLUDED («исключён»)**. **«Вернуть»** включает выбранный тайл вручную и запоминает решение для той же версии файлов. **«Проверить чёрные тайлы»** повторяет проверку. Исходники, маски, разметка и исключённые PNG сохраняются. После изменения активных тайлов нужен пересчёт измерений; прежние файлы измерений остаются целыми.

4. На странице **«Сегментация»** импортируйте YOLO-полигоны и нажмите **«Измерить в выбранном режиме»** или **«Измерить с автопоиском при отсутствии TXT»**. Пустой TXT означает ноль объектов. После расчёта проверьте выбранный тайл на вкладках **Native**, **«Модель»**, **«Объекты»** и **«Полигоны YOLO»**. Во вкладке «Объекты» выберите части щелчками по маскам или галочками у номеров и нажмите **«Объединить выбранные части»**.
5. В **«Разметке объектов → Галерее объектов»** назначьте тип одной из шести кнопок или клавишей 1–6. Класс сразу сохраняется, затем открывается следующий объект. «Открыть тайл объекта» показывает его точную подсвеченную маску. Для проверенных меток доступен «Экспорт обучающего CSV».
6. **«Обучение модели»** оценивает модель по проверенным меткам.
7. Последняя страница **«Результаты»** содержит **«Графики»**, **«Таблицу признаков»** и экспорт CSV, Excel и набора для ML. Экспорт видимых строк учитывает собственные фильтры таблицы этой страницы.

В **«Результатах»** также доступны копия полной таблицы измерений в Excel, ZIP для ML с согласованными по строкам CSV признаков, целей и метаданных объектов с ручным типом и статистика по текущему набору. Вкладка «Графики» строит гистограммы, диаграммы рассеяния, ящики с усами, матрицы выборочной ковариации и корреляции Пирсона.

«Новый проект» запрашивает имя папки и родительский каталог, затем создаёт `<каталог>/<имя>/project.json`. Внутри каждого проекта находятся свои `sources`, `previews`, `runs` (тайлы, raw-фрагменты и анимации), импортированные `datasets`, `annotations`, `measurements` (с фрагментами объектов) и `jobs`. «Добавить TIFF» копирует точные исходные байты фоновым заданием с отменой; для больших файлов нужны время и свободное место. Начальный пустой проект находится в `data/projects/default/project.json`; TIFF не добавляются автоматически. Каждый новый вариант параметров создаёт отдельный запуск.

Подключение готового набора сначала копирует его в проект. «Исключить», «Вернуть» и обновление карты меняют только эту копию; внешний набор, native-файлы и маски сохраняются.

Примеры папок: `sources/FL01_G3_RGB_Red.tif`, `runs/Preparation_001/tiles/FL01_G3_RGB_Red`, `previews/FL01_G3_RGB_Red/Preview_001`, `annotations/FL01_G3_RGB_Red/Labels_001`, `measurements/FL01_G3_RGB_Red/Measurement_001`. UUID остаются внутренними ID в JSON. Старые управляемые папки переименовываются с точной копией проекта и журналом отката в `backups/Storage_layout_001`; байты измерений, ручных меток и их идентичность сохраняются. Обязательные для v3 `native`, `valid_masks` и `overview` остаются. Временные папки удаляются после операции.

**«Срез/кадр TIFF»** — индекс глубины Z, времени T или изображения I с нуля, отдельно от канала. Значение 3 выбирает четвёртый срез. Для обычного 2D или RGB TIFF плоскость одна, поэтому 0 доступен только для чтения. Проекция и объединение стека не выполняются.

**«Из метаданных TIFF»** показывает масштаб выбранного исходника только для чтения и определяет его отдельно для каждого файла пакета. Поддерживаются положительные, конечные и одинаковые X/Y (относительный допуск 1e-6) из OME PhysicalSizeX/Y либо единицы ImageJ с обратными X/YResolution. Единица OME по умолчанию — мкм; 400 нм/px дают 0.4 мкм/px. Печатный DPI, увеличение объектива, неизвестные единицы и неодинаковые X/Y автоматически не используются. **«Вручную / исходные пиксели»** задаёт одно значение всему пакету; 0 оставляет пиксельные единицы. Новый запуск/измерение сохраняет итоговый масштаб и его происхождение; прежние результаты и заводской справочник не меняются. Основание: [схема OME](https://www.openmicroscopy.org/Schemas/Documentation/Generated/OME-2015-01/ome_xsd.html) и [документация метаданных tifffile](https://www.cgohlke.com/docs/tifffile/).

## Справка и безопасные настройки

Кнопка **«Справка / Help»** открывает поиск по руководству приложения и справочник параметров обработки. **F1** показывает справку по активному параметру или текущей странице. Ту же статью можно открыть кнопкой **?** или командой **«Объяснить параметр / Explain this parameter»** в контекстном меню поля.

На начальной странице есть пошаговое руководство по обработке одного TIFF. В разделах рабочего процесса сначала идут практические инструкции, затем подробности и ссылки на связанные настройки. Поиск принимает несколько слов, например `пустой TXT` или `Excel ML`.

В справочнике над подробной справкой расположена таблица сравнения параметров. Выберите строку, чтобы открыть статью снизу, или найдите настройку в оглавлении по этапам. В статьях указано, где находится поле, как проверить результат, какие единицы и правила проверки действуют и с какими настройками связан параметр. Заводские значения берутся из неизменяемого каталога версии 3, а текущие — из снимка формы, включая несохранённые правки.

Команда **«Справка → Вернуть сохранённые настройки / Restore saved settings»** возвращает форму к последним успешно сохранённым параметрам проекта. **«Восстановить заводские настройки / Restore factory defaults»** возвращает полный исходный набор для последующей обработки; контекстная команда **«Вернуть заводское значение / Use factory default»** сбрасывает только одно поле. Эти действия меняют настройки, сохраняя готовые запуски и разметку.

**«Настройки…»** в верхней панели собирают все параметры обработки и начальные значения обоих редакторов. Найдите параметр по названию или ключу, сравните с заводским значением и сохраните параметры проекта. Отдельная галочка запоминает параметры обработки для новых проектов. Значения редакторов применяются при их открытии.

Недопустимые значения выделяются красным: рядом показаны диапазон и заводское значение. Их нельзя сохранить или использовать для обработки; закрытие окна оставляет прежние корректные сохранённые параметры. Если старый проект уже содержит неверные настройки, при запуске сначала создаётся точная побайтовая копия исходного файла в отдельной папке `.recovery`, затем исправляются только некорректные поля. Валидные значения и данные проекта сохраняются, изменения записываются в историю; неизвестные параметры остаются в резервной копии, а их удаление отражается в истории.

## Фильтры и расположение панелей

**«Линейка»** показывает длину в пикселях исходника при известном преобразовании и в микрометрах при сохранённой калибровке. Если преобразование неизвестно, используются пиксели файла. Shift выравнивает отрезок по оси, Esc очищает измерение. Для точного выбора концов откройте Native.

В **«Подготовке → Выбор фильтров»** можно включать отдельные шаги и менять их параметры:

| Шаг | Настройка | Параметры по умолчанию |
|---|---|---|
| Bilateral-сглаживание | `enable_bilateral` | Диаметр 9; сигма яркости 45; пространственная сигма 15 |
| White top-hat | `enable_tophat` | Радиус 85; эллиптическое ядро 171 × 171 и последующая min–max-нормализация |
| Gamma-коррекция | `enable_gamma` | Gamma 1.2; показатель степени `1/gamma` |
| Морфологическое замыкание | `enable_closing` | Эллиптическое ядро 17 × 17; только защитная маска |
| Защитное расширение | `enable_dilation` | Эллиптическое ядро 5 × 5; только защитная маска |

Все пять шагов включены по умолчанию, в том числе при открытии старого проекта без этих переключателей. Выключение шага сохраняет его параметры. Замыкание и расширение меняют защитную маску маршрутизации, а не отфильтрованное изображение или маску физического диаметра. Защитный порог Otsu рассчитывается по текущему grayscale и при отключённых фильтрах. Готовые тайлы сохраняют прежние настройки; изменения применяются к предпросмотру и новой подготовке.

Перетаскивайте заголовки панелей, чтобы менять их расположение. Двойной щелчок по заголовку выносит панель в отдельное окно или возвращает её. Меню **«Панели / Panels»** показывает и скрывает панели; **«Восстановить расположение панелей / Reset panel layout»** возвращает исходный вариант. Расположение сохраняется между запусками.

Панели изображений, отдельные окна и полноэкранный режим используют общую панель значков. В широком окне кнопки увеличиваются, а в узкой панели переносятся на следующую строку. Перетаскивание перемещает изображение. Колесо и значки лупы меняют масштаб. Значок разворачивания или двойной щелчок открывает отдельное окно, **F11** включает полный экран.

В меню **«Линейка»** доступны отрезок и ломаная. Щелчок добавляет вершину, двойной щелчок или **Enter** завершает ломаную. Правый щелчок по отрезку меняет его цвет. У линейки, рисуемого контура и импортированных полигонов YOLO есть настройки цвета и толщины (1–12 экранных пикселей). При рисовании контура следующая сторона следует за курсором. Замкнутая фигура без самопересечений показывает периметр, площадь и диаметр круга той же площади. Для фрагмента объекта используется калибровка его версии измерений.

В **«Подготовке»** или **«Сегментации»** выберите **«Сравнить рядом → Открыть окно сравнения»**. Значок двух изображений также открывает **«Сравнить с файлом…»**. Если ширина и высота совпадают, включите **«Наложение»** и задайте непрозрачность второй картинки от 0 до 100%. При сравнении каналов нужны совпадающие координаты съёмки и ориентация.

Значок ползунков открывает **«Яркость и контраст»** с уровнями чёрного и белого и сбросом. Это настройка просмотра. Через значок сохранения экспортируйте отдельную копию в TIFF, PNG или JPEG. **«Сохранить видимое изображение»** включает уровни и видимые наложения в разрешении предпросмотра. **«Экспортировать сохранённый файл»** использует полный файл. В том же формате сохраняются исходные байты, при конвертации используется первый кадр. TIFF и PNG сохраняют 16-битные серые значения из файла. JPEG использует 8 бит и сжимает с потерями.

У числовых полей видны кнопки **+** и **−** с прежними шагами и пределами; ядра морфологии по-прежнему меняются на 2. Колесо не меняет числа, выбранные пункты, ползунки и регуляторы даже при фокусе: над параметром оно прокручивает форму. Прокрутка раскрытого списка сохраняется; над изображением колесо меняет масштаб. **«По размеру окна»** скрывает полосы прокрутки; после приближения они появляются только по тем осям, где картинка больше окна. Перетаскивание перемещает её без искусственных пустых полей.

Меняйте размеры панелей разделителями между ними. В «Тайлах» опускайте горизонтальный разделитель над сведениями и действиями вниз, отдавая картинке больше высоты, или поднимайте для показа действий. Его положение сохраняется. Вернуть отдельную панель можно перетаскиванием заголовка в подсвеченную область рабочего окна: рядом с другой панелью или во вкладки. Кнопки заголовка выносят/возвращают панель, разворачивают/восстанавливают отдельное окно и закрывают его. Двойной щелчок по заголовку тоже возвращает панель. Отдельные окна оригиналов поддерживают разворачивание. **«Восстановить расположение панелей»** остаётся средством восстановления.

**1:1** открывает сохранённый файл отдельно в исходном разрешении. В «Подготовке» эта кнопка открывает просмотр участков в исходных пикселях. На вкладке «Карта» она строит подробную карту границ в размерах исходника. При прямом открытии файла больше 32 Мп используется просмотрщик Windows.

В **«Разметке объектов»** выберите объект и нажмите **«Открыть тайл объекта»**. Его измеренная маска, ID и рамка выделяются золотым цветом. Флажок **«Подсветить объект»** скрывает и показывает выделение. Предпочтителен native-фрагмент; резервное модельное поле пересчитывает координаты по масштабу. Новые измерения сохраняют точную маску и координаты в `verification_masks/object_locations.json`. Для старых серых фрагментов используется единственное точное совпадение яркостей; неоднозначный результат требует пересчёта. Подсветка не меняет изображение или признаки.

Добавлена иконка SoLoData для окон и панели задач. Команда `powershell -NoProfile -ExecutionPolicy Bypass -File tools/create_shortcut.ps1` создаёт ярлык `SoLoData.lnk` рядом с `launch_app.cmd`. После перемещения программы пересоздайте ярлык. Редактируемая иконка находится в `src/desktop/assets/solodata.svg`; `tools/build_icon.py` пересобирает PNG/ICO.

## Поиск прямого коридора и редактор тайлов

В редакторах тайла и масок **«Курсор рисования»** предлагает крест, точку, стрелку и прицел. Указатель выбирается независимо от размера кисти или ластика. В редакторе тайла **«Сравнить с оригиналом…»** открывает исходник рядом со снимком применённых правок, включая несохранённые.

В **«Подготовке → Поиск прямого коридора»** поле **«Конец исходного окна поиска»** задаёт правую или нижнюю границу окна в исходных пикселях. Пиксель на границе в окно не входит. При стороне тайла 1500 px режим **«Автоматически»** даёт окно `[1125, 1462)`. Введите 1400, чтобы получить `[1125, 1400)` и до 100 px сдвига вправо или вниз. Начало окна равно 75% стороны тайла с округлением вниз. При стороне 1500 px для конца окна допустимы значения 1126–1500 px, а предел влево или вверх равен 750 px.

Ползунки и числовые поля задают пределы перемещения первого окна. При стороне 1500 px полный шаг равен 22 px. Ручной предел 30 px даёт пробы на 22 и 30 px при необходимости. Заводские пределы сдвига — **«Автоматически»** влево или вверх и 0 вправо или вниз. Если прямой коридор не найден, Дейкстра ищет путь в настроенном первом окне. Настройки применяются при новой подготовке.

В **«Тайлах»** откройте вид **«Модель»** или **Native** кнопкой **1:1**, затем нажмите **«Редактировать тайл»**. Редактор также доступен через **«Разметка объектов → Открыть тайл объекта»**.

**«Кисть (B) → Взять яркость пипеткой»** считывает текущую native-яркость выбранного действительного пикселя. Рисуйте этой яркостью или задайте её вручную. Радиус кисти — 0–150 исходных пикселей (заводской 3). Радиус 0 даёт линию толщиной один пиксель. Пипетка сохраняет значения 8/16 бит, кисть действует внутри действительной области. Ctrl+Z возвращает состояние до штриха. Правка записывает ручной синтетический сигнал, точку образца, яркость и путь. Последующие версии сохраняют этот флаг. Перед назначением классов и обучением пересчитайте и проверьте изменённую маску измерений.

- **«Отсечь по линии»** продлевает проведённую прямую до краёв тайла. Щёлкните со стороны удаления или нажмите **«Меньшая сторона»**, чтобы выбрать её по числу действительных пикселей. Проверьте подсветку и нажмите **«Применить»** для заполнения нулевым паддингом. Прямой и свободный ластики стирают только по следу кисти.
- **«Удалить фон локально»** применяет white top-hat в прямоугольнике. В режиме **«Яркость (гамма)»** выберите **«Выделить прямоугольник»** для любого участка, **«Последняя область фона»** для прежней области фильтра или **«Весь тайл»**. Проверьте предпросмотр и нажмите **«Применить»**. Гамма 1,00 соответствует исходной яркости, а значения выше осветляют тёмные и средние тона. Начальный радиус ластика — 60 px из неизменяемого каталога настроек редактора.

Перед сохранением сравните с оригиналом и при необходимости отмените правку. **«Сохранить тайл»** публикует активную версию с согласованными native/model-изображениями, маской и журналом правок. В Tile images показана эта версия. После редактирования пересчитайте измерения, проверьте новые объекты и назначьте типы перед экспортом или обучением. Random Forest получает числовые признаки этих проверенных объектов. Предыдущие измерения и отчёты моделей сохраняют сведения о своих входных версиях.

Кнопка **«Использовать сохранённую правку…»** активирует прежний экспорт по файлу `edit.json` после проверки исходника и масштаба. Поддерживаются native-экспорты и модельные экспорты с одним исходным пикселем на пиксель модели. Правки старых уменьшенных модельных экспортов повторите на native. **«Вернуть подготовленный тайл»** снова выбирает подготовленное изображение. При предупреждении об устаревшей обзорной карте перестройте её. Окно редактирования 1:1 открывает native-пиксели, в том числе из вкладки «Модель».

Порог очистки задаёт нижнюю границу яркости на 8-битном обрабатываемом изображении. Локальная доля Otsu умножает порог Otsu, найденный внутри контура кандидата. При T > 10 итоговый порог равен `max(минимум, int(T × доля))`. В маску измерения входят пиксели строго ярче него. При фиксированном T=80, минимуме 25 и доле 0,70 порог равен 56, а при доле 0,45 — 36. Слабая середина с яркостью 40 и фон с яркостью 38 проходят пониженную границу. После изменения этих полей или локальной гаммы сравните тот же native-участок и проверочные маски.

## Измерения

**«Сегментация → Сегментация по пикселям…»** обучает отдельный пиксельный лес на точных проверенных масках. Выберите наборы, классы переднего плана и число деревьев. Изначально отмечены частицы и волокна. Модель использует предполагаемый фон вдали от измеренных масок и строит PNG классов и цветное наложение для активного native-тайла. Модели и прогнозы хранятся в `pixel_segmentation` проекта. Выход представляет семантическую карту без независимой тестовой оценки.

Крупный объект может уменьшаться для помещения в модельный тайл, при сохранении native-фрагмента и масштаба. Для v3 признаки вычисляются по native-изображению. `Area` — исходные пиксели; при заданной калибровке доступна площадь в µm². `Aspect_Ratio` — большая ось маски / малая ось маски и не требует множителя масштаба. Длина изогнутого волокна по скелету пока не является этим AR.

`Endpoints` и `Branch_Points` описывают скелет; Branch_Points сохраняет прежнее определение количества пикселей ветвления. Защитная маска гарантирует сохранение её целых связных компонент, а не экспертное распознавание всех биологических объектов.

В **«Подготовке»** сначала проверьте **«Исходный канал»**, затем сравните его с **«Фильтрацией»** и проверьте целостность волокон на **«Защитной маске»**. Быстрый предпросмотр ограничен 2400 пикселями. **«Просмотр в исходном разрешении»** и **1:1** открывают основной вид в масштабе один пиксель источника на физический пиксель экрана. Перетаскивайте изображение, меняйте масштаб колесом или щёлкайте по уменьшенной карте для перехода. Видимые исходные пиксели подгружаются по мере навигации. Для фильтрации и защитной маски первый запрос может заново запустить обработку всей плоскости и сохранить два полноразмерных TIFF. Готовые варианты используются повторно.

Кнопка **«Объединить каналы TIFF…»** в «Подготовке» объединяет выбранные каналы одного среза или кадра. Задайте каждому цвет, усиление яркости от 0 до 1600% и непрозрачность от 0 до 100%. Цветные вклады суммируются с ограничением каждого компонента RGB. Выход — RGB8 исходного размера. TIFF подходит для больших изображений и сохраняет поддерживаемую калибровку. PNG и JPEG доступны до 32 Мп.

В **«Тайлах»** найдите фрагмент по **«Карте»**. **«Модель»** показывает холст для модели и YOLO, **Native** — исходную сетку фрагмента, **«Принадлежность»** — действительные пиксели, **«Полигоны»** — импортированные контуры YOLO. Вкладки тайла до 32 Мп загружают сохранённые пиксели целиком. Кнопка **«Редактировать выбранный тайл…»** открывает редактор. «Курсор рисования» находится под выбором инструмента.

В **«Настройки → Внешний вид»** выбираются стартовый курсор и масштаб интерфейса. Значки в списке показывают формы курсоров. Автоматический режим увеличивает текст и кнопки вместе с главным окном. Доступен фиксированный масштаб от 100% до 200% поверх масштаба Windows. Яркость и контраст в просмотрщике сдвигают и меняют ширину линейного интервала между чёрным и белым. Гамма использует нелинейную кривую, а bilateral и white top-hat учитывают соседние пиксели. Уровни действуют на экран и экспорт видимого изображения.

В **«Результаты → Графики»** перетаскивайте область построения для панорамирования и прокручивайте колесо для масштаба. Горизонтальный разделитель меняет высоту графика, а **«Настройки графика»** сворачивают верхнюю панель. В меню **«Цвета графика»** доступны цвет данных, фон и палитра матрицы. Отдельное окно графиков можно перемещать и разворачивать.

## Выполнение и восстановление

Вычисления идут в отдельном процессе. «Остановить» запрашивает отмену в безопасной точке; текущая операция фильтра может завершиться до остановки. Закрытие с принудительным завершением оставляет стадию неполной. При повторном запуске проверенный результат подготовки используется повторно; неполная стадия пересчитывается новой версией.

Ошибки показываются в журнале и сохраняются рядом с запросом задания. Нулевой анализ создаёт новый пустой CSV с заголовками. Неполный v3 без manifest не допускается к измерению.

## Связные маски и удаление шума

В **04 «Сегментация → Объекты»** выберите маски и нажмите **«Соединить концы / Править маску»**. Редактор приближает выбранную область. Пары концов предлагаются по расстоянию и направлению продолжения; другую пару можно выбрать в списках или инструментом **«Выбрать концы A / B»**. **«По сигналу изображения»** ищет путь минимальной стоимости в голубой рамке; **«Прямая линия»** соединяет точки напрямую. Проверьте розовый предпросмотр и нажмите **«Добавить показанный мост»**. Смена концов, метода, толщины или запаса поиска требует нового предпросмотра. Утолщается только мост.

**«Кисть (B)»** и **«Ластик (E)»** работают от руки. Для проверки доступны **«Панорама (H)»**, колесо масштаба, **«Приблизить выбор»**, **«Показать исходную маску»**, **Ctrl+Z / «Отменить штрих»**. Толщина — нечётное число **1–101 native px**, запас поиска — **4–256 px**. Заводской каталог редактора масок v1 задаёт толщину моста **3**, кисти **7**, запас **48**. Поиск ограничен **1 000 000 пикселей ROI**, редактор — **32 Мп**. Добавления не могут выходить за активную принадлежность или касаться невыбранной маски, включая диагональный контакт.

**«Выделить все маски» (Ctrl+A)** отмечает все объекты текущего тайла. **«Править маски раздельно»** сохраняет ID каждого объекта и позволяет стирать по всем отмеченным маскам одним штрихом. В поле **«Маска для кисти»** выберите ID для свободной дорисовки или **«По затронутым маскам»** для отпечатков кисти там, где её центр проходит по каждой отмеченной маске. Добавления обходят другие маски и паддинг. Сохранение создаёт одну версию измерений и требует, чтобы каждая изменённая маска осталась непустой и 8-связной. Проверьте ручные классы изменённых объектов.

**«Сохранить связную маску»** требует одну непустую 8-связную компоненту. Создаётся новая версия Measurement с пересчётом шести признаков и калиброванной площади; класс нового объекта нужно проверить заново. Otsu больше не разделяет принятую маску в этой версии. Записываются пути, толщина, хеши исходников и ручные добавления; последние остаются розовыми в «Объектах» после открытия и последующих объединений. Яркости native/model и TXT YOLO сохраняются. Серые фрагменты содержат реальные яркости, поэтому бинарный мост там может выглядеть тёмным. Мост — ручная реконструкция, а не наблюдаемое биологическое доказательство.

**«Удалить выбранные маски»** убирает выбранные объекты шума из текущего CSV, масок, фрагментов, классов, графиков и обучающего экспорта. **«Отменить изменение масок»** возвращает родительскую версию целиком, даже после удаления всех объектов. Невыбранные ID и классы сохраняются. Предыдущие версии остаются на диске. Полный новый расчёт запускает сегментацию заново: шум может вернуться, а ручные мосты не переносятся вслепую на изменившийся ввод. Обычное **«Объединить выбранные части»** по-прежнему группирует точные маски вместе с разрывами. **? / F1** объясняет инструменты, заводские значения, ограничения и восстановление в приложении.

## Ручные классы для Random Forest

**«Сегментация → Объекты → Объединить выбранные части»** берёт поэлементное объединение минимум двух точных масок одного активного тайла. В новой неизменяемой версии Measurement пересчитываются все шесть признаков и физическая площадь при наличии калибровки. Промежутки сохраняются; яркости тайла и TXT YOLO не меняются. Общие пиксели считаются один раз. Несвязанные части могут стать одним проверенным объектом, поэтому признаки формы и топологии отражают оставшиеся разрывы. Метки остальных объектов переносятся; новый объект нужно разметить заново. **«Отменить последнее объединение»** возвращает родительское измерение целиком вместе с метками; объединённая версия остаётся на диске. Старые результаты без точных бинарных масок и устаревшие измерения требуют пересчёта. Полный новый расчёт начинает сегментацию заново без этих решений об объединении.

«Галерея объектов» показывает реальные контрольные фрагменты, сохранённые при извлечении признаков. Выберите карточку для подробного просмотра и нажмите одну из шести кнопок типа или клавишу **1–6**: класс сохранится и откроется следующий объект. **←/→** перемещают по видимым объектам, **U** находит следующий без класса. В галерее можно выбрать тайл, искать объекты/классы и показывать только неразмеченные объекты; в таблице признаков действуют отдельные поиск и фильтр классов.

В «Дополнительных действиях» доступны список классов и кнопки «Сохранить класс / Сохранить и дальше». Выбор «Без класса» с сохранением снимает прежнюю метку. Клавиши **1–6** соответствуют ID классов **0–5** в таблице ниже; сохранённые ID начинаются с нуля.

| ID | Ключ в CSV | Класс |
|---|---|---|
| 0 | particle | Частица |
| 1 | fiber | Волокно |
| 2 | self_crossed_tube | Пересечение трубочки самой собой |
| 3 | crossed_tubes | Перекрещенные трубочки |
| 4 | agglomeration | Агломерация |
| 5 | adhered_objects | Несколько слипшихся объектов |

Метки хранятся в `manual_object_labels.sqlite3` рядом с конкретной версией измерений. Одно назначение записывает только выбранную метку и событие изменения одной транзакцией, без перезаписи CSV признаков и JSON проекта. Старые `manual_object_labels.json` проверяются и переносятся при первом сохранении; их исходные байты сохраняются. Привязка к набору, измерению, тайлу, объекту и хешу CSV остаётся обязательной. Полный повторный расчёт начинает новую разметку; исправление масок переносит метки только неизменённых объектов, отмена возвращает родительскую версию.

**«Дополнительные действия → Экспорт снимка меток (JSON)…»** сохраняет актуальные метки для совместимых старых программ на отдельной копии проекта. В полную резервную копию включайте базу меток, `manual_object_labels_storage.json` и исходный JSON. Если база отсутствует или повреждена, её нужно восстановить из копии: старый JSON не подставляется молча. Отдельный каталог `project.sqlite3` по-прежнему содержит восстанавливаемые метаданные.

«Экспорт обучающего CSV / Export training CSV» выгружает только объекты с назначенным классом: научные числовые признаки, `Manual_Class_ID`, `Manual_Class`, `Reviewed` и идентификаторы источника/измерения. Ключи и ID в CSV остаются стабильными.

Для обучения предусмотрены `Area`, `Aspect_Ratio`, `Solidity`, `Euler_Number`, `Endpoints`, `Branch_Points`. При калибровке также доступна `Area_um2`. `Manual_Class_ID` — целевая метка. Исходные `Class_ID`/`Class_Name` YOLO, ID источника и версия измерений сохраняются в CSV как справочная информация и исключены из списка входных признаков.

Страница **«Обучение модели»** принимает объекты с ручными метками из наборов проекта или обучающей таблицы `.xlsx` или `.csv`. Выберите классы объектов и число деревьев в лесу. Проверьте план 80/20 и числа объектов по классам. В режиме по умолчанию TIFF или эксперимент остаются целиком в одной части. Стратификация по объектам даёт оценку на тех же исходниках, в том числе на одном TIFF. Необязательный подбор по K фолдам сравнивает Gini и энтропию только на обучающей части. Графики данных показывают числа объектов, распределения признаков, корреляцию Пирсона и критерии информативности. При наличии теста сравнивайте прогноз частого класса, дерево и лес по macro-F1, полноте классов и матрице ошибок. Отчёты сохраняют снимок данных и прогнозы в `model_evaluations`. **«Сохранить выбранную модель»** выгружает обученный классификатор объектов файлом `.joblib`.

**«Галерея разбиения»** показывает сохранённые объекты обучения, отложенного теста и каждого проверочного фолда. Через **«Проверка новых объектов…»** сохранённое дерево или лес предсказывает классы измеренных объектов без ручной метки на выбранных тайлах. Снимок прогнозов и отметки проверки сохраняются в `object_predictions` проекта отдельно от обучающих меток.

Каталог классов общий с YOLO. ID 0–4 сохраняют исходную нумерацию: `Sphere` соответствует частице, `Curve` — волокну. Слипшиеся объекты добавлены как класс 5. `Class_Catalog_Version=2` фиксирует соответствие. Старые ручные метки читаются по сохранённому смысловому ключу и переводятся на эти ID при следующем сохранении; просмотр и экспорт не перезаписывают прежний файл меток.

Полное руководство приложения, справочник параметров, восстановление настроек и горячие клавиши доступны без интернета через **Справка / F1**. Научные изображения, производные примеры, локальные отчёты аудита и результаты проверок остаются локальными и исключены из публичного репозитория.
