# SoLoData

Прежнее название — FiBreath. Существующие проекты, язык и расположение панелей совместимы с обновлением. Название репозитория Fibers-Segmentation сохранено.

[Описание обновления SoLoData](docs/SOLODATA_RELEASE_2026-10-29_RU.md).

Локальное Windows-приложение для обработки микроскопических TIFF, подготовки тайлов, проверки и исключения изображений, импорта YOLO segmentation и извлечения признаков.

Английский язык используется по умолчанию. В верхней панели можно выбрать русский или иврит (`עברית`); выбор сохраняется. Знак **?** показывает краткое объяснение при наведении, а при нажатии открывает подробную справку.

## Запуск

Дважды нажмите **launch_app.cmd**. На этом компьютере он выбирает готовое научное окружение `bm-336546`. Приложение использует Qt: доступный PyQt6 или PySide6. Интернет для работы не требуется.

Альтернативный запуск из корня проекта:

```powershell
& "$env:USERPROFILE\anaconda3\envs\bm-336546\python.exe" -B app.py
```

Для другого компьютера установите Python 3.10+ и зависимости в локальное окружение:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Для запуска на иврите можно добавить `--language he`; этот аргумент переопределяет язык на один запуск:

```powershell
& "$env:USERPROFILE\anaconda3\envs\bm-336546\python.exe" -B app.py --language he
```

Также поддерживаются `--language en` и `--language ru`. Интерфейс на иврите расположен справа налево; числовые поля, координаты изображений, имена файлов и технические таблицы сохраняют направление слева направо. Язык не меняет ключи параметров, ID классов и столбцы CSV.

## Рабочий процесс

1. Создайте проект или откройте существующий файл проекта. Выберите исходные TIFF, канал и плоскость.
2. В «Подготовке» проверьте настройки и предварительный фрагмент. Наведите на **?** для краткой подсказки, нажмите на него или **F1** для подробной справки. Запустите подготовку выбранных изображений.
3. В «Тайлах» проверьте обзор, модельные и native-изображения, исключите лишние ID и отметьте набор проверенным. Можно подключить прежний набор нарезки через папку с его `overview`/`native`/`valid_masks`.
4. На странице **«Сегментация / Segmentation»** импортируйте YOLO-полигоны или нажмите **«Выделить объекты и назначить типы / Detect objects and assign types»**. Кнопка использует имеющуюся разметку и автоматически выделяет объекты только на тайлах без TXT. Пустой TXT по-прежнему означает отсутствие размеченных объектов. После расчёта открываются «Результаты».
5. В **«Результатах → Галерее объектов»** выберите сохранённый фрагмент объекта и назначьте тип одной из шести кнопок. Класс сразу сохраняется, затем открывается следующий объект. «Таблица признаков» позволяет проверить и выгрузить научные значения; для проверенных меток используйте «Экспорт обучающего CSV».

Предыдущие результаты подготовки не перезаписываются: каждый новый вариант параметров создаёт отдельный запуск. Приложение сохраняет проект, версии разметки, журналы и результаты в своей рабочей папке. Начальный проект находится в `data/ui_projects/default/project.json`. Открытие приложения автоматически добавляет заголовки существующих TIFF в список исходников, но не запускает обработку и не изменяет прежние данные.

Подключение существующего набора только читает его. Явные действия «Исключить» и «Вернуть» перемещают верхнеуровневые модельные тайлы в выбранном наборе; native-файлы и маски сохраняются.

## Справка и безопасные настройки

Кнопка **«Справка / Help»** открывает поиск по 12 разделам приложения и справочник всех 28 параметров pipeline. **F1** показывает справку по активному параметру или текущей странице. Можно нажать на **?** либо выбрать **«Объяснить параметр / Explain this parameter»** в контекстном меню поля; подсказки при наведении также работают.

Справочник раздельно показывает **заводское значение / Factory default** и **текущее значение / Current value**, единицы, допустимый диапазон, примеры и влияние изменения параметра. Заводские значения — неизменяемый исходный набор версии 1, независимый от проекта и правок `config.py`. Окно справки только читает значения и не применяет настройки или обработку.

Команда **«Справка → Вернуть сохранённые настройки / Restore saved settings»** возвращает форму к последним успешно сохранённым параметрам проекта. **«Восстановить заводские настройки / Restore factory defaults»** возвращает полный исходный набор для последующей обработки; контекстная команда **«Вернуть заводское значение / Use factory default»** сбрасывает только одно поле. Эти действия меняют настройки, сохраняя готовые запуски и разметку.

Недопустимые значения выделяются красным: рядом показаны диапазон и заводское значение. Их нельзя сохранить или использовать для обработки; закрытие окна и смена языка оставляют прежние корректные сохранённые параметры. Если старый проект уже содержит неверные настройки, при запуске сначала создаётся точная побайтовая копия исходного файла в отдельной папке `.recovery`, затем исправляются только некорректные поля. Валидные значения и данные проекта сохраняются, изменения записываются в историю; неизвестные параметры остаются в резервной копии, а их удаление отражается в истории.

## Фильтры и расположение панелей

В **«Подготовке → Выбор фильтров»** можно включать отдельные шаги и менять их параметры:

| Шаг | Настройка | Параметры по умолчанию |
|---|---|---|
| Bilateral-сглаживание | `enable_bilateral` | Диаметр 9; сигма яркости 45; пространственная сигма 15 |
| White top-hat | `enable_tophat` | Радиус 85; эллиптическое ядро 171 × 171 и последующая min–max-нормализация |
| Gamma-коррекция | `enable_gamma` | Gamma 1.2; показатель степени `1/gamma` |
| Морфологическое замыкание | `enable_closing` | Эллиптическое ядро 17 × 17; только защитная маска |
| Защитное расширение | `enable_dilation` | Эллиптическое ядро 5 × 5; только защитная маска |

Все пять шагов включены по умолчанию, в том числе при открытии старого проекта без этих переключателей. Выключение шага сохраняет его параметры. Замыкание и расширение меняют защитную маску маршрутизации, а не отфильтрованное изображение или маску физического диаметра. Защитный порог Otsu рассчитывается по текущему grayscale и при отключённых фильтрах. Готовые тайлы сохраняют прежние настройки; изменения применяются к предпросмотру и новой подготовке.

Перетаскивайте заголовки панелей, чтобы менять их расположение. Двойной щелчок по заголовку выносит панель в отдельное окно или возвращает её. Меню **«Панели / Panels»** показывает и скрывает панели; **«Восстановить расположение панелей / Reset panel layout»** возвращает исходный вариант. Расположение сохраняется между запусками.

Во всех просмотрах изображений перетаскивание перемещает картинку, колесо и **+/−** меняют масштаб. Значок полного экрана, двойной щелчок по изображению или **F11** при фокусе на изображении открывают полный экран; **Esc** или **F11** возвращают рабочую область. Это работает для исходного и отфильтрованного фрагмента, защитной маски, карты и тайлов, масок принадлежности, полигонов и выбранного объекта. Просмотр не меняет файлы или масштаб измерений.

## Измерения

Крупный объект может уменьшаться для помещения в модельный тайл, при сохранении native-фрагмента и масштаба. Для v3 признаки вычисляются по native-изображению. `Area` — исходные пиксели; при заданной калибровке доступна площадь в µm². `Aspect_Ratio` — большая ось маски / малая ось маски и не требует множителя масштаба. Длина изогнутого волокна по скелету пока не является этим AR.

`Endpoints` и `Branch_Points` описывают скелет; Branch_Points сохраняет прежнее определение количества пикселей ветвления. Защитная маска гарантирует сохранение её целых связных компонент, а не экспертное распознавание всех биологических объектов.

Предпросмотр фрагмента приблизительный: нормализация включённого top-hat и защитный Otsu рассчитываются по фрагменту, а полная подготовка использует всё исходное изображение. Каждый запуск сохраняет собственный снимок параметров. Точность распознавания биологических объектов оценивается отдельно по экспертной разметке.

## Выполнение и восстановление

Вычисления идут в отдельном процессе. «Остановить» запрашивает отмену в безопасной точке; текущая операция фильтра может завершиться до остановки. Закрытие с принудительным завершением оставляет стадию неполной. При повторном запуске проверенный результат подготовки используется повторно; неполная стадия пересчитывается новой версией.

Ошибки показываются в журнале и сохраняются рядом с запросом задания. Нулевой анализ создаёт новый пустой CSV с заголовками. Неполный v3 без manifest не допускается к измерению.

## Выбор набора и готовые тайлы

«Набор / Dataset» — список подготовленных наборов текущего проекта. Пока TIFF не подготовлен и прежние тайлы не открыты, список пуст. Кнопка «Открыть тайлы… / Open tiles…» позволяет подключить существующие результаты.

«Открыть подготовленные тайлы / Open prepared tiles» открывает папку одного набора, ранее созданного этим pipeline, например `data/2_sliced_tiles_1500/FL01_G3_RGB_Red`. Внутри нужны модельные PNG, `native`, `valid_masks` и `overview/*_tiles_coords.json` версии v3. Это позволяет перейти к проверке и измерениям без повторной фильтрации TIFF. Родительскую папку всех наборов выбирать не нужно.

## Ручные классы для Random Forest

«Галерея объектов» показывает реальные контрольные фрагменты, сохранённые при извлечении признаков. Выберите карточку для подробного просмотра и нажмите одну из шести кнопок типа или клавишу **1–6**: класс сохранится и откроется следующий объект. **←/→** перемещают по видимым объектам, **U** находит следующий без класса. В галерее можно выбрать тайл, искать объекты/классы и показывать только неразмеченные объекты; в таблице признаков действуют отдельные поиск и фильтр классов.

В «Дополнительных действиях» доступны список классов и кнопки «Сохранить класс / Сохранить и дальше». Выбор «Без класса» с сохранением снимает прежнюю метку. Клавиши **1–6** соответствуют ID классов **0–5** в таблице ниже; сохранённые ID начинаются с нуля.

| ID | Ключ в CSV | Класс |
|---|---|---|
| 0 | particle | Частица |
| 1 | fiber | Волокно |
| 2 | self_crossed_tube | Пересечение трубочки самой собой |
| 3 | crossed_tubes | Перекрещенные трубочки |
| 4 | agglomeration | Агломерация |
| 5 | adhered_objects | Несколько слипшихся объектов |

Метки хранятся отдельно в `manual_object_labels.json` рядом с конкретной версией измерений. Исходные признаки и классы YOLO не заменяются. После повторного расчёта создаётся новая версия объектов без ручных меток; метки предыдущей версии остаются в прежней папке результатов. Изменение разметки или состава тайлов требует пересчёта перед назначением классов и экспортом.

«Экспорт обучающего CSV / Export training CSV» выгружает только объекты с назначенным классом: научные числовые признаки, `Manual_Class_ID`, `Manual_Class`, `Reviewed` и идентификаторы источника/измерения. Язык интерфейса не меняет ключи и ID в CSV.

Для обучения предусмотрены `Area`, `Aspect_Ratio`, `Solidity`, `Euler_Number`, `Endpoints`, `Branch_Points`; при калибровке также доступна `Area_um2`. `Manual_Class_ID` — целевая метка. Исходные `Class_ID`/`Class_Name` YOLO, ID источника и версия измерений сохраняются в CSV как справочная информация и исключены из списка входных признаков. Передача класса на вход модели раскрыла бы ей правильный ответ. Обучение и применение Random Forest пока не реализованы; этот процесс готовит для них датасет.

Каталог классов общий с YOLO. ID 0–4 сохраняют исходную нумерацию: `Sphere` соответствует частице, `Curve` — волокну. Слипшиеся объекты добавлены как класс 5. `Class_Catalog_Version=2` фиксирует соответствие. Старые ручные метки читаются по сохранённому смысловому ключу и переводятся на эти ID при следующем сохранении; просмотр и экспорт не перезаписывают прежний файл меток.

Полное руководство приложения, справочник параметров, восстановление настроек и горячие клавиши доступны без интернета через **Справка / F1**. Актуальная публикация описана в [обновлении SoLoData](docs/SOLODATA_RELEASE_2026-10-29_RU.md). Научные изображения, производные примеры, локальные отчёты аудита и результаты проверок остаются локальными и исключены из публичного репозитория.
